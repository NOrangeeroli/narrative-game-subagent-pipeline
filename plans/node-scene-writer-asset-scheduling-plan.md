# NodeSceneWriter Asset Scheduling Plan

## Scope

Rename and expand `NodeDialogueWriter` into `NodeSceneWriter` so each VN or cutscene node is authored as a complete playable scene, not only dialogue and narration. The writer should produce Yarn fragments that already contain concrete background, character, expression, BGM, SFX, and scene-flow cues. Asset generation should then be driven from those accepted scene scripts plus their manifests.

This is a post-design pipeline change. It must not change the public design layer outputs: `branch_graph.json` and `game_ir.json` stay unchanged.

## Current Problem

- `NodeDialogueWriter` owns the text, while `AssetDirector` and `PresentationDirector` own much of the sensory staging later.
- This separation lets assets be generated without being scheduled in Yarn, which caused missing runtime audio such as absent `play_bgm`, `play_sfx`, or line voice attachment.
- The name `NodeDialogueWriter` now understates the role. The role is really writing a node-level VN scene with performance direction.
- `AssetDirector` currently has too much creative responsibility after the scene is already written, so it can guess assets that do not match the actual beat-by-beat reading experience.

## Target Design

`NodeSceneWriter` becomes the scene author for one `vn_yarn` or `cutscene_yarn` realization plan.

It writes:

- Player-facing narration, dialogue, and monologue.
- Concrete scene description through playable prose, not metadata prose.
- Background changes with `show_bg`.
- Character entrance, exit, portrait, expression, and action staging with `show_char`, `set_expression`, and `hide_char`.
- CG cues when a beat needs a dedicated illustration.
- Scene-level music scheduling with `play_bgm` and `stop_bgm`.
- Moment-level sound scheduling with `play_sfx`.
- Per-line delivery notes in the fragment manifest for voice generation: speaker, exact text, tone, emotion, and optional voice profile id.

Voice should still not become a Yarn command. It remains line-attached audio during export, because voice playback belongs to the line beat itself.

## Role Changes

### `NodeSceneWriter`

Create a new post-design role card:

```text
references/subagents/post-design/NodeSceneWriter.md
```

Responsibilities:

- Replace `NodeDialogueWriter` as the primary spawn role for `vn_yarn` and `cutscene_yarn`.
- Treat every node as a coherent playable scene with orientation, active tension, reveal or turn, and motivated exit.
- Author valid Yarn presentation/audio commands directly where the scene needs them.
- Use only local asset ids that can later be planned and generated.
- Write a manifest that records all local asset refs, command refs, and line-level voice/performance intents.
- Keep source adaptation notes private and never expose planning labels or reader-facing analysis in runtime text.

### `NodeDialogueWriter` Compatibility

Keep `NodeDialogueWriter.md` temporarily as a compatibility alias that points to `NodeSceneWriter`.

Expected follow-up:

- Existing documentation can mention that `NodeDialogueWriter` is deprecated.
- Existing pipeline references should spawn `NodeSceneWriter`.
- Tests or fixtures that assert `generated_by: NodeDialogueWriter` should accept either old or new value during the transition.

### `AssetDirector`

Do not delete `AssetDirector` immediately. Narrow it into an asset consolidation role.

New responsibilities:

- Read accepted Yarn fragments and manifests.
- Consolidate duplicate asset intents across nodes.
- Preserve character identity and expression naming consistency.
- Maintain global style pack and prompt discipline.
- Convert scene-authored asset refs into `asset-direction.json`.
- Add missing prompt detail only when an asset ref is already justified by accepted scene scripts.
- Reject or report asset refs that are impossible, inconsistent, or unscheduled.

Removed or reduced responsibilities:

- It should not invent major scene staging after Yarn is already accepted.
- It should not decide where BGM/SFX should play if the scene writer already supplied valid commands.
- It should not create voice assets unrelated to exact dialogue or monologue line beats.

### `PresentationDirector`

Remove this role from the V2 workflow. `NodeSceneWriter` now owns scene staging
directly, including character presence, expression/action cues, BGM, and SFX.
If staging is weak, repair the relevant scene fragment instead of adding a
post-hoc presentation plan.

## Artifact Changes

### Yarn Fragment Pair

Update the contract text to say the fragment may be generated by `NodeSceneWriter`.

Keep the existing canonical paths:

```text
workspace/vn/fragments/<node-id>.yarn
workspace/vn/fragments/<node-id>.manifest.json
```

The Yarn command set remains unchanged:

```text
show_bg, show_char, set_expression, hide_char, show_cg, hide_cg,
play_bgm, stop_bgm, play_sfx, complete_activity, set, wait
```

### Manifest Extension

Add an internal optional field to fragment manifests:

```json
{
  "line_performance": [
    {
      "line_index": 1,
      "speaker": "赵没有",
      "text": "exact spoken line",
      "tone": "tired, defensive",
      "emotion": "uneasy",
      "voice_id": "voice_profile.zhao_meiyou",
      "action": "looks away before answering"
    }
  ]
}
```

Rules:

- `line_index` is 1-based and counts spoken, monologue, and narration line beats exactly as the exporter counts them.
- `text` must exactly match the player-facing line if a voice asset may be generated.
- Voice entries are valid only for spoken dialogue or inner monologue, not ambience or unspoken scene description.
- `tone`, `emotion`, and `action` are private generation/staging notes and must not appear in player-facing text.

This does not affect `branch_graph.json` or `game_ir.json`.

## Controller And Script Changes

1. Add `NodeSceneWriter.md`.
2. Replace SKILL workflow references from `NodeDialogueWriter` to `NodeSceneWriter`.
3. Update `references/subagents/README.md` to list `NodeSceneWriter` as the primary post-design scene role and mark `NodeDialogueWriter` as legacy alias.
4. Update `references/artifact-contracts.md`:
   - allow `generated_by: NodeSceneWriter`
   - document `line_performance`
   - clarify that BGM/SFX scheduling belongs in scene Yarn when known
5. Add or update a controller extraction step:
   - parse accepted Yarn commands and fragment manifests
   - collect `bg.*`, `cg.*`, `portrait.*`, `bgm.*`, `sfx.*`, and `voice.*` intents
   - use `line_performance` plus exact line text to create voice asset directions
6. Update `AssetDirector.md` so it consumes extracted scene asset intents and returns consolidated `asset-direction.json`.
7. Update validation:
   - fail if Yarn references local asset ids that are absent from `asset-direction.json` or `asset-manifest.json`
   - fail if `play_bgm` or `play_sfx` references an unplanned audio asset
   - fail if a voice asset lacks exact line text, speaker, and node trace
   - warn when a VN/cutscene has no background, no music cue, or no character staging despite requiring them
8. Update export/report checks:
   - keep BGM/SFX command export as command-driven runtime playback
   - keep voice export as line-attached playback
   - report unvoiced dialogue lines separately from missing BGM/SFX command coverage

## Migration Steps

1. Create `NodeSceneWriter.md` by adapting the current `NodeDialogueWriter.md`.
2. Convert `NodeDialogueWriter.md` into a short alias/deprecation card.
3. Update skill workflow docs and subagent index.
4. Update artifact contracts for `NodeSceneWriter` and `line_performance`.
5. Add an asset-intent extraction helper that can derive `asset-direction.json` inputs from accepted Yarn fragments and manifests.
6. Narrow `AssetDirector.md` to consolidation, consistency, and prompt compilation.
7. Remove `PresentationDirector` from the role index, contracts, workflow docs,
   and build-time application path.
8. Add validation around scheduled-but-unplanned assets and unvoiced line coverage.
9. Run a small fixture through init/build using mock assets.
10. Run a real VN adaptation smoke test with model-backed visual/audio assets.

## Acceptance Criteria

- New runs spawn `NodeSceneWriter` for VN/cutscene nodes.
- Accepted Yarn fragments contain the core runtime staging needed by the scene: background, character/expression cues, and audio cues when appropriate.
- `asset-direction.json` can be generated or consolidated from accepted scene scripts without inventing unrelated assets.
- `play_bgm` and `play_sfx` commands survive through StoryIR, Web VN export, and browser runtime playback.
- Dialogue or monologue voice assets are attached by exact line matching and reported in `web-vn-export-report.json`.
- `AssetDirector` remains useful as a global asset consistency layer, not as the primary scene staging author.
- The public design layer interface remains unchanged.

## Non-Goals

- Do not change `branch_graph.json` or `game_ir.json` schemas.
- Do not add a new design-layer role.
- Do not make voice a Yarn command.
- Do not remove `AssetDirector` until extracted scene asset intents are stable across several runs.
